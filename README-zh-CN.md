## 简介

AtomUI.Icons.Gravity 是面向 AtomUI OSS 框架的图标库封装，基于 Gravity UI Icons 项目，提供统一的 API 与命名规范，让你在 AtomUI 中即可使用 Gravity UI 图标，并以原生矢量方式渲染。

## 主要特性
- 覆盖 Gravity UI 图标的两种风格：Outlined（常规）/ Filled
- 816 个图标、28 个分类，全部由上游 SVG 源文件生成
- 与 AtomUI 的 Icon 组件无缝接入，统一的使用体验
- 图标实例化不依赖反射，对 AOT 与裁剪友好
- 支持基础的尺寸、颜色、旋转、动画等常用定制
