## Introduction

AtomUI.Icons.Gravity is an icon library wrapper for the AtomUI OSS framework, built on the Gravity UI Icons project. It provides a unified API and naming conventions, enabling you to use Gravity UI icons within AtomUI as native vector icons.

## Key Features
- Covers Gravity UI icon styles: Outlined (regular) / Filled
- 816 icons in 28 categories, generated from the upstream SVG sources
- Seamless integration with AtomUI’s Icon component, with unified properties and events
- Icon instantiation without reflection, friendly to AOT and trimming
- Supports basic customization for size, color, rotation, animations, and more
